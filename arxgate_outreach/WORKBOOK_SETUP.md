# ArxGate Outreach Workbook Scaffold

This folder contains the initial scaffold for building `arxgate_global_resource.xlsx`.

## Files

- `Master_Resources.csv` — master target list with outreach-tracking columns
- `Picklists.csv` — controlled vocabulary for dropdowns
- `Dashboard.csv` — starter metrics and Excel formulas

## Recommended Workbook Tabs

1. `Master_Resources`
2. `Dashboard`
3. `Picklists`
4. Optional regional tabs derived from the master sheet

## Recommended Next Steps

1. Populate `Master_Resources.csv` with 300+ global targets.
2. Import all CSVs into Excel.
3. Save workbook as `arxgate_global_resource.xlsx`.
4. Apply data validation rules in Excel using `Picklists`.
5. Convert `Master_Resources` into an Excel Table.
6. Build pivot tables or charts from `Dashboard` as needed.

## Outreach Tracking Columns

The master sheet includes fields for:

- Status
- Outreach Owner
- First Contact Date
- Last Contacted
- Next Follow-Up
- Outreach Stage
- Reply Status
- Meeting Status
- Opportunity Status

These fields can drive formulas and pivot tables on the dashboard.
